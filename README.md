# Cyber-security-week-1-
Cyber Security Risk Assessment in E-Governance
This project presents a cybersecurity risk assessment of a representative e-governance and digital public-service portal.
The assessment identifies major cybersecurity risks including data breaches, phishing, account takeover, injection attacks, DDoS attacks, malware/ransomware, insider threats, and outdated software or security misconfiguration.
The project evaluates the likelihood and impact of each risk and proposes appropriate mitigation strategies based on recognized cybersecurity practices and publicly available guidance.
Tools/References: NIST Cybersecurity Framework, OWASP Top 10, CERT-In guidance and CISA resources.
Project Type: Cybersecurity Risk Assessment
Internship Task: Week 1
Domain: E-Governance & Digital Services
